# Bharti Luxury Hotel — Luxury Hotel Landing Page (React + Tailwind CSS)

A pixel-faithful React & Tailwind CSS implementation of the luxury hotel landing page design under the **Bharti Luxury Hotel** brand name, featuring alternating midnight obsidian (`#0D1117`) and warm alabaster cream (`#F6F4F0`) S-wave bands, champagne gold (`#D4B584`) accents, Cormorant Garamond serif headings, and interactive booking/countdown components.

## Quick Start

1. Extract the ZIP folder and open it in your terminal or VS Code.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the local development server:
   ```bash
   npm run dev
   ```
4. Open the local URL shown in your terminal (e.g., `http://localhost:5173`).
